# Матрица ошибок

| Сценарий | Как воспроизвести | Ожидаемая диагностика | Действия оператора |
|---|---|---|---|
| Нет бакета | Отдельная BSL с уникальным несуществующим именем и валидным административным ключом | Unavailable; NoSuchBucket / does not exist; Backup FailedValidation/Failed | Проверить endpoint, регион и имя; создать приватный бакет; дождаться Available |
| Неверный ключ | Отдельная BSL с несуществующим Access Key ID | Unavailable; InvalidAccessKeyId/AccessDenied | Выпустить правильную пару ключей, обновить Secret, проверить BSL; не печатать ключи |
| Доступ запрещён | Существующий пользователь MinIO с явной Deny-политикой | Unavailable; AccessDenied/Forbidden | Проверить bucket/object ARN и разрешения List/Get/Put/Delete/multipart; убрать ошибочный Deny |
| Прерывание Restore | Заблокировать node-agent, дождаться PVR и активного Restore, перезапустить Velero | Restore Failed или PartiallyFailed; отдельный PVR может позднее завершиться | Вернуть node-agent, сохранить логи; удалить частичный namespace; новый Restore в чистый namespace |
| Ошибка pg_dump | Недоступна БД/недостаточно диска/старая блокировка | Ошибка pre-hook; Backup не принимается | Исправить причину, проверить свободное место; повторить копию; не удалять исходные данные |
| Ошибка импорта | Повреждён дамп/не совпадает SHA/ошибка SQL | PostgreSQL не проходит проверку; нет RESTORE_IMPORT_COMPLETED | Сохранить лог, выбрать другую копию; повторить в новом namespace |
| Backup Completed, данных нет | Пропущена аннотация тома | Нет завершённого PVB с ненулевыми bytes | Проверить аннотацию backup-volumes и node-agent; копировать заново |
| Несовпадение данных | Изменить строку при сохранении количества записей | SHA-256 различается, verify FAIL | Не переключать приложение; расследовать момент дампа и изменения данных |

Тесты трёх ошибок S3 не меняют рабочую BSL. Временные BSL и Secret очищаются в `finally`.
Незавершённые резервные копии остаются как диагностические CR до ручной очистки/истечения TTL.
В наблюдаемом сценарии после возврата node-agent отдельный PVR мог перейти в Completed, тогда как
Restore оставался PartiallyFailed. Успех PVR не заменяет успешную фазу всего Restore и проверку приложения.
Сообщения разных версий S3 могут различаться, поэтому проверяется категория, фаза и реальный отказ Backup.
Если операция завершилась до инъекции прерывания, это FAIL теста, а не успешная проверка сбоя.

Тест прерывания предназначен для выделенного учебного Velero. Перезапуск сервера затрагивает все его
активные операции; на общем кластере вместо этого используйте отдельную установку и согласованное окно.
